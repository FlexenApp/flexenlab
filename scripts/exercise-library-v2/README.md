# Exercise Library v2 — Data & Media Pipeline

Reproducible pipeline to populate 1500 Firestore `exercises` with clean names, German translations, and WebP images.

## Run Order

```
build-media  →  upload-media  →  translate-de  →  reseed-exercises --confirm  →  verify
```

## Prerequisites

- Node 18+
- Auth (one of):
  - `GOOGLE_APPLICATION_CREDENTIALS` pointing to a service account JSON, OR
  - `~/.flexen/serviceAccountKey.json`
- `GEMINI_API_KEY` env var (required only for `translate-de.js`)

## Steps

### 1. Build WebP media (GIF → animated + thumb)
```bash
node build-media.js
# Smoke-test: node build-media.js --limit=2
```
Produces: `webp/anim/<exerciseId>.webp`, `webp/thumb/<exerciseId>.webp`

### 2. Upload media to Firebase Storage
```bash
node upload-media.js
```
Produces: `media-manifest.json` with `gifUrl`/`thumbUrl` per exercise.

### 3. Translate exercise names + instructions to German
```bash
GEMINI_API_KEY=<key> node translate-de.js
```
Produces: `de-cache.json` (resumable; re-run to continue after interruption).

### 4. Dry-run re-seed (review sample doc)
```bash
node reseed-exercises.js
```

### 5. Backup + write to Firestore (requires explicit go)
```bash
node backup-exercises.js --stamp=YYYY-MM-DD
node reseed-exercises.js --confirm
```

### 6. Verify acceptance checks
```bash
node verify.js
```
Expected: `✓ ALL ACCEPTANCE CHECKS PASS`

## Gitignored outputs

- `webp/` — converted media (rebuild from source GIFs)
- `media-manifest.json` — regenerated by upload-media
- `de-cache.json` — translation cache (regenerated by translate-de)
- `backups/` — Firestore snapshots before re-seed
